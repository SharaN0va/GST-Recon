# VeRecon

Desktop GST reconciliation software designed for fast, structured reconciliation and audit-ready Excel reporting.

## Key Features
- **Fast Reconciliation:** Compare client accounting records against GST data to surface mismatches quickly.
- **Audit-Ready Excel Exports:** Generate clean, structured Excel summaries suitable for review, ITC decisions, and notice replies.
- **Keyboard- & Mouse-Friendly Interface:** Built with a responsive desktop UI for rapid office workflows.
- **Local Processing:** Files are processed locally on your computer without uploading client data to external servers.

## Download & Setup
1. Open the **Releases** section on this repository.
2. Download the latest Windows release package (`.exe` or `.zip`).
3. Extract the archive (if zipped) and run the executable.
4. Enter your license key when prompted (for licensed or beta builds).

## System Requirements
- **OS:** Windows 10 or Windows 11 (64-bit)
- **Storage:** ~200 MB free disk space plus space for input/output Excel files
